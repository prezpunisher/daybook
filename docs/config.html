How it works

  1. strategy.json in trade-advisor holds the live rules. The bot reads it every morning; the Small account page tests it.
  2. Run backtest sends your draft to a GitHub job, which checks it and replays it on 2 years of real option prices.
  3. Make live copies a finished backtest's rules into strategy.json. Only drafts within the bot's hard limits can go live.
  4. The bot's guard (in the private rh-bot repo) enforces its own ceilings, so nothing on this page can make it trade bigger than those.
  5. Every change is a GitHub issue and a commit, so there's a full history of who changed what and when.
